# BiTFI implementation and evaluation scripts

This snapshot accompanies *Bidirectional imputation of missing greenhouse sensor data using frozen time-series foundation models*.

## Main entry points

- `dafi.py`, `clean_batched_bitfi.py`: BiTFI implementation (the historical internal identifier is DAFI).
- `clean_protocol.py`, `run_clean_evaluation.py`: physical screening, train-prefix scaling, common masks and model evaluation.
- `train_saits.py`, `train_moment_head.py`: trained comparison models.
- `run_validation_context_selection.py`: univariate selection using only training-site validation tails.
- `run_selected_context_evaluation.py`, `run_selected_univariate_control.py`: selected-context main evaluation and matched-input backbone comparison.
- `figures/`: plotting sources; `legacy/` and earlier experiment entry points preserve historical work and are not the current benchmark.

The selected maximum context is 1,900 hourly positions for Chronos 2, TimesFM2.5 and TimesFM3; it is held fixed across each backbone’s input configurations. Candidate lengths were 96, 168, 336, 720, 1080, 1440 and 1900 h. The validation selection covers 1,393 gaps from 21 eligible training greenhouses.

## Runtime and artifacts

The code uses Python, PyTorch, pandas/numpy/scipy/scikit-learn, plotting libraries, and the model-specific Chronos, TimesFM, AutoGluon, SAITS and MOMENT packages. `requirements.txt` records the project requirements; model backends were run in separate environments, including a dedicated TimesFM3 environment. CUDA devices and cached model checkpoints must be configured for the target machine.

Downloaded pretrained weights, trained checkpoints, evaluation outputs, Python caches and local assistant instructions are not part of this source snapshot. Several publication scripts consume intermediate files under `03_result/`, generated by preceding preprocessing/training/evaluation steps. For a fresh checkout, run `python 02_model/initialize_public_paths.py` to resolve the filenames in `01_data/split.json` into `03_result/comparison/split.json`; this refuses to overwrite an existing experiment. Then run `python 02_model/clean_protocol.py` to generate physically screened data, frozen scalers and evaluation masks. A complete experiment requires generating these intermediate artifacts; cloning alone does not provide saved results or weights.

## Component, information and agronomic experiments

The revised comparison includes 21 configurations; main performance plots use one common 12-setting display set defined in `revision_config.py`. `SAITS-local` and `SAITS-cross` are matched 24-channel controls, separate from the original five-channel SAITS checkpoint. Both jointly model local targets; MOMENT alone uses independent target channels.

After preparing the original clean protocol, trained checkpoints, validation context selection and main evaluation artifacts:

1. Run `revision_saits_spatial.py --prepare`, then `--train local`, `--train spatial` and `--evaluate` in the standard environment.
2. Run `run_revision_refinement.py --smoke`; then run three independent shards using `--shard 0/1/2 --shards 3` in the TimesFM3 environment. Assign each worker a GPU through `CUDA_VISIBLE_DEVICES`. Each reports initialization and 1, 2, 3 and 5 synchronous refinement passes. One pass remains the specified method; the test diagnostic does not select the default.
   Run `reconcile_revision_batches.py --prepare`, then its `--shard 0/1/2` workers. This reproduces original production batch groups for cases whose case-level NMAE differs by more than 0.00001; all refinement depths are recomputed for each selected complete group. The analysis overlays those records and verifies the remaining numeric tolerance.
3. Run `revision_additional_sites.py --prepare`, then run it without arguments in the TimesFM3 environment. This uses the nine excluded sites' three common indoor variables without tuning.
4. Run `check_revision_equivalence.py`, `analyze_revision_experiments.py`, and `render_revision_figures.py`. Results are saved in `03_result/revision_experiments_20260926`; the plotting code reads the selected-context main benchmark and the new controls.

Use `torch.set_float32_matmul_precision('highest')` **after** loading TimesFM3: its loader changes the precision setting. The refinement and additional-site entry points enforce this ordering. The diagnostic uses hourly air VPD and integrated **outdoor broadband radiation**; it does not measure crop yield, transpiration, canopy PAR or daily light integral.

Measured versions: TimesFM3 environment: timesfm 3.0.1, PyTorch 2.14.0/CUDA 13.0; standard environment: PyTorch 2.6.0/CUDA 12.4, Transformers 4.57.6, chronos-forecasting 2.2.2, AutoGluon-TimeSeries 1.5.0; both use NumPy 2.1.3 and pandas 2.3.3. Hardware and timing scopes are recorded by each experiment. SAITS sources are expected under `third_party/SAITS` from the official [WenjieDu/SAITS](https://github.com/WenjieDu/SAITS) repository; model weights and this external source tree are not redistributed here.

Manuscript editing, publication validation and packaging utilities additionally require the local `05_thesis` TeX/PDF assets; that manuscript directory is not included in this data/code repository. The authored graphical abstract is also separate from the computational experiments.
